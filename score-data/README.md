# Score data (Phase 1 + 2 output)

Generated by `tools/extract_movie.py` -> `tools/parse_score.py` ->
`tools/scene_summary.py` from the original game files:

```
python3 tools/extract_movie.py <gamedir>/mizube.exe movie.cxt
python3 tools/parse_score.py   --movie movie.cxt --game <gamedir> --out score
python3 tools/scene_summary.py --score-dir score --game <gamedir> --out score
```

## What was found

The embedded main movie inside mizube.exe (XFIR/MV93 at 0x86c8c8, mmap
offsets EXE-absolute -> rebased) contains the full Director score:

- **VWSC** - 2,197 frames declared (21,973 records incl. animation frames),
  1,006 channels (200 displayed), framesVersion 14, 48-byte sprite records,
  D6+/D7-family delta-compressed channel patches (ScummVM
  `engines/director/score.cpp` layout, adapted for D11.5)
- **VWLB** - 328 markers (frames 340..21631): `{u16 count, u16 ver=11}`,
  entries `{u16 strOff, u16 frame}` (last = terminator), name blob at
  `count*4+6`, labels delimited by consecutive strOffs
- **Sord** - the movie-internal cast order (47 members)
- **MCsL/Lnam** - cast-lib list + string pool
